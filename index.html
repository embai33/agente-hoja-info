    Acerca de esta aplicación

    Ejercicio paso a paso para construir la cadena de agentes que genera una hoja informativa de medicamentos a partir de una ficha técnica hablando con Claude Code en lenguaje natural, con bloques de texto listos para copiar y seguimiento de tu progreso.

    Material formativo con carácter exclusivamente informativo y educativo. Los documentos generados deben ser revisados por un profesional sanitario antes de cualquier uso clínico.
